# WB_HartJohnstoneForestClassesAI_S5_5 0.0.1

* First version. Converts Biomass_core `cohortData` and `pixelGroupMap` into a forest class
  map (deciduous, coni-deci mix, conifer mix, pine, larch, spruce; NA = non-forest), using
  biomass as the proxy for species dominance.
* New reusable functions `classifyForestClasses()` and `writeForestClassRaster()` in the `R` folder.
